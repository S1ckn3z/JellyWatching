What It Does

JellyWatching is a Jellyfin plugin that tracks consecutive episode playback per user and device. After a configurable threshold it pauses playback and asks the viewer to confirm they're still there.

Features

  • Episode count and watch-time thresholds with flexible trigger modes
  • Auto-pause with a customizable on-screen message
  • Night mode for stricter limits during specific hours
  • Per-user setting overrides
  • Activity detection — seeking or switching tracks resets the timer
  • Web-based configuration from the Jellyfin dashboard

Quick Install

Add this repository URL in Dashboard → Plugins → Repositories:

Name: JellyWatching

https://s1ckn3z.github.io/JellyWatching/manifest.json

Then open the Catalog, find JellyWatching under General, install it, and restart Jellyfin.
